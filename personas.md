# Personas — AutoGest

## Persona 1 — Le Patron

| Persona | Description |
|---|---|
| **Nom** | Michel Dupont |
| **Tranche d'âge** | 45-55 ans |
| **Profession** | Garagiste artisan, propriétaire du garage |
| **Objectifs** | Gérer son garage sans paperasse, créer des devis et factures rapidement, suivre ses encaissements, organiser les RDV |
| **Frustrations** | Perd du temps avec les devis papier, oublie des RDV, ne sait pas toujours ce qu'il a encaissé dans le mois |
| **Comportements** | Utilise un PC à l'atelier, son téléphone quand il est chez un client, pas très à l'aise avec l'informatique |

## Persona 2 — L'Employé

| Persona | Description |
|---|---|
| **Nom** | Kevin Martin |
| **Tranche d'âge** | 25-35 ans |
| **Profession** | Mécanicien employé du garage |
| **Objectifs** | Consulter les RDV du jour, saisir les réparations effectuées et les pièces utilisées |
| **Frustrations** | Ne sait pas toujours quels véhicules sont prioritaires, perd du temps à chercher les infos d'un client |
| **Comportements** | Utilise surtout le téléphone ou une tablette dans l'atelier, les mains souvent occupées |
